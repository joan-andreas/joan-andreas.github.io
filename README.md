# Joan Andreas — Portfolio

Personal portfolio site built with Vite + Vanilla JS.
Live at: https://joan2305.github.io

## Development
```
npm install
npm run dev
```

## Deploy
Push to `main` → GitHub Actions builds and deploys automatically.

## To update CV
Replace `public/cv.pdf` with the new file. Push to `main`.

## Contact form
Uses Formspree. Replace `YOUR_FORMSPREE_ID` in `index.html` with your endpoint.
